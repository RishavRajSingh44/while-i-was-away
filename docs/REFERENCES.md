## Integration contracts

GitHub's [pull-request schema](https://docs.github.com/en/graphql/reference/pulls) provides `state`, `isDraft`, `mergedAt`, `reviewDecision`, `mergeable`, `reviews`, `reviewThreads` and `statusCheckRollup`. Group merged first, then closed, then open draft/ready. `UNKNOWN` mergeability is not a failure or approval. Review threads contain inline discussion; top-level issue comments alone are insufficient. Connections require cursor pagination and visible truncation when application bounds are reached. A local branch-name match is a hint; forks can share branch names. Never infer merge status from prose.

`headRefOid` is the authoritative current head object ID for a PR. The Entire adapter shows an associated PR only when a locally verified linked code commit exactly matches this hash. This deliberately misses older commits in a PR rather than inferring a false association from a branch name.

`gh api graphql` receives GraphQL variables separately from the query. The manual documents `$endCursor` and `pageInfo { hasNextPage endCursor }` for pagination. This app uses bounded explicit page loops so partial data can be identified. `gh` authentication belongs to the user's CLI configuration; the application stores neither token nor authentication output.

Ollama chat returns JSON text in `message.content`; a schema-shaped `format` does not establish factual correctness. The application must parse the JSON, validate allowed fields/citations, and preserve deterministic Git/GitHub facts separately. Model tags may change: model digest and prompt version belong in cache identity. Local Ollama can run cloud-tagged models; selecting such a tag must not silently send source data remotely.

## Model baseline

[Gemma 3 4B in Ollama](https://ollama.com/library/gemma3:4b) is the configurable default. The explicit `ollama pull gemma3:4b` download was about **3.4 GB**; the tested model digest, 48 GiB Apple arm64 host and real run are recorded in [VALIDATION.md](VALIDATION.md). Gemma weights use [Gemma Terms](https://ai.google.dev/gemma/terms), not this application's MIT license. Download size is not peak RAM, and one successful host does not establish smaller-machine requirements. No model is bundled or downloaded by the app. Model weights and OSI-licensed application software are different categories.
